# StockPilot — C++ Inventory Management System

A C++ inventory management project demonstrating object-oriented programming.

## Features
- Product class and inventory class
- Add and display products
- Search products
- Stock quantity and price
- Low-stock status
- Browser-based presentation demo in `web/index.html`

## C++ Concepts
Classes, objects, constructors, vectors, methods, loops and conditional statements.

## Run C++
```bash
g++ main.cpp -o inventory
./inventory
```

For the browser demo, open `web/index.html` with VS Code Live Server.
